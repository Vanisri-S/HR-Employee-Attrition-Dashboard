# HR Employee Attrition Dashboard
## Project Overview
This project analyzes the IBM HR Employee Attrition dataset using SQL and Power BI. The objective was to explore employee attrition patterns, answer business questions through SQL, and build an interactive dashboard to help stakeholders understand workforce trends and support data-driven decisions.
## Objectives
- Analyze employee attrition using SQL.
- Build an interactive Power BI dashboard.
- Create meaningful KPIs using DAX.
- Present business insights through effective data visualization.
- Improve dashboard usability with interactive slicers and filters.
## Tools & Technologies
- SQL (MySQL)
- Power BI
- DAX
